# LiberLightPDF

## Project Overview
LiberLightPDF is a modern, feature-rich PDF editor and viewer built with React and TypeScript. It allows you to view, annotate, draw, highlight, erase, take per-page notes, and export your edited PDFs with all your changes and notes included. The app also features a motivational duck to keep you inspired while you work!

Check the demo at : [https://liberlightpdfeditor.netlify.app/]
## Tech Stack
- **React 18**
- **TypeScript**
- **Vite**
- **shadcn/ui** (component library)
- **Tailwind CSS**
- **pdfjs-dist** (PDF rendering)
- **jsPDF** (PDF export)

## Features
- **PDF Viewing**: Open and view multi-page PDFs with smooth navigation.
- **Annotation Tools**:
  - Draw (pen tool)
  - Highlight
  - Erase
  - Undo/Redo
- **Zoom In/Out**: Magnify or shrink the PDF view.
- **Motivational Duck**: Get cheerful reminders and motivational messages while you work.
- **Per-Page Notes**: Take and save notes for each page. All notes are included at the bottom of each page when exporting the PDF.
- **Save/Export**: Download your annotated PDF with all edits and notes preserved.
- **Dark Mode**: Easy on the eyes with a full dark mode UI.
- **Full Screen Mode**: Focus on your PDF with a distraction-free full screen experience.
- **Responsive Design**: Works great on desktops and tablets.

## Getting Started

### Prerequisites
- Node.js (v16 or higher recommended)
- npm

### Installation
```sh
# Clone the repository
git clone <YOUR_GIT_URL>

# Install dependencies
npm install

# Start the development server
npm run dev
```

The app will be available at [http://localhost:8080](http://localhost:8080) by default.
